## Shared runtime changes

- The existing native DXGI adapter can wrap a composition swap chain created on a D3D12 direct queue. It uses the current back buffer and queues GPU copies into the same shared texture and fence protocol that the Xbox presenter already reads. This covers single-queue RGBA8 and BGRA8 swap chains up to 1920 × 1080. Factory and swap-chain versions are exposed based on native interface support. [Direct3D 12 swap chains](https://learn.microsoft.com/en-us/windows/win32/direct3d12/swap-chains) · [Composition swap chain contract](https://learn.microsoft.com/en-us/windows/desktop/api/dxgi1_2/nf-dxgi1_2-idxgifactory2-createswapchainforcomposition)
- The package builder can stage an optional source profile for Big Picture **Play**. The authenticated launch checks the installed Steam build, sizes and SHA-256 before invoking Steam or preparing a local compatibility copy. The launch report identifies the first file that fails and the observer exposes the result. [Source profile options](../probe/GAME-LAUNCH.md#verify-owned-windows-files-before-a-trial)
- Nixxes locates PC saves under Documents, and the reference runtime exports a Documents adapter through its shell DLL. An opt-in Win32 profile can now bind the same shell call to a persistent Documents directory scoped to the signed-in Steam account and AppID. The isolated `--desktop-documents` control checks folder creation, write and readback. The game’s own save and reload and any Steam Cloud behavior still need separate Xbox verification. [Nixxes save location](https://support.nixxes.com/hc/en-us/articles/48438595745043-I-am-stuck-or-can-t-progress-the-game) · [Documents profile](../probe/GAME-LAUNCH.md#scope-a-win32-trials-documents-folder)

The D3D11 and D3D12 exchange controls both returned `0x51A7` on Xbox in packages `1.0.230.185` and `1.0.230.186`. The D3D12 control rendered alternating colors, verified the pixels through a second device, retired the shared texture slots and repeated the exchange after resizing. This verifies the shared GPU path in the control. Later Spider-Man trials reached the same presentation path with a black frame.
