# Steam Store navigation on Xbox

The Series X package `1.0.230.37` opened the original Store route in run `6564c4a7-7173-4a9d-89a9-ea762d46c8bc`. The isolated WebView2 controller confirmed its empty initial document, then the native host accepted the public HTTPS navigation. The report contains neither a subsequent public navigation start nor an HTTP result. The TV showed Valve's loading indicator. The runtime reason for the missing native callback is still unknown. [Console Store results](big-picture-reliability.md#build-1023037)

Two independent completion gaps are visible in the bridge. A `LoadURL` can wait forever when the isolated browser returns neither a start nor a completion. On an explicit failed completion, Valve's pinned `OnLoadError` records the error fields but leaves its loading flag set. Its `OnFinishedRequest` clears the flag. The adapter should give an outstanding public request a deadline, stop the expired native load, settle Valve's loading state on error, and keep failed destinations out of committed history. Reload should retry the failed public destination even when the prior native document was blank. A terminal browser or renderer process failure should reach the same failure path. Keep the isolated controller and its existing origin checks. [Store bridge](../ui/big-picture-bridge/xbox-store-browser.js) · [Native Store surface](../ui/big-picture-webview/store-browser.h)

WebView2 provides a navigation ID at the first start and keeps that ID through redirects. The native adapter records the expected public URL and binds matching starts, redirects, and completions to the original request. If a request is replaced before its first start, the native adapter recreates the isolated controller and clears its history. This also disambiguates a same-URL retry when the old request never acquired a navigation ID. [WebView2 navigation events](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/navigation-events)

The native input queue drains accepted releases after the Store loses focus or visibility. It drops pending presses from the old focus interval and clears all queued edges when a controller is replaced. [Native Store surface](../ui/big-picture-webview/store-browser.h)

Microsoft documents reduced browser activity on hidden controllers.
