# Steam download queue and prerequisite paths

## Download queue [#55](https://github.com/clankur/GabeBox/issues/55)

The earlier queue diagnostic kept the last nonzero competing AppID for the lifetime of an install. A later poll could report `active=selected` or `active=none` paired with that old AppID. The current tree dropped the draft diagnostic altogether. The native install path still samples Steam's current active AppID on every poll, and the broker copies the native checkpoint fields into the saved download report.

Publish both queue fields from that one sample on each poll, including resume and terminal checkpoints. Compute the competing ID directly from the current sample. Keep Steam's own queue placement and transfer metrics. Cover the competing → selected and competing → idle transitions, plus a competing → different competing title transition.

## Shared prerequisite paths [#54](https://github.com/clankur/GabeBox/issues/54)

Series X build `1.0.54.0` requested a writable library for Common Redistributables, but Steam retained the read-only package. In `1.0.58.0`, the pinned app-manager install override let Steam write a completed manifest to the writable library. The same process then returned the library root as Slay the Spire's installation directory. A fresh `1.0.60.0` process resolved the title directory and Steam accepted Play. Dwarf Fortress repeated the path error in `1.0.80.0` and advanced to a separate process-startup failure after restart. [Recorded Steam Core trials](../docs/STEAM-CORE.md#test-steams-normal-launch-path)

Current Play verifies the selected game's completed manifest and its exact Steam directory before checking its dependencies. The consolidated tree kept the normal dependency request and dropped the writable override and restart logic. The app manager's pinned `ForceInstallDirOverride` takes a directory, normalizes it and can create a `steamapps` directory. The inspected implementation does not establish an empty-string reset. Replacing Steam's directory with the manifest-derived directory would let Play continue without verifying Steam's own launch state.

Reintroduce the writable override only when Steam chooses the read-only package for a required incomplete redistributable. Once the override is applied, mark the process as requiring restart for subsequent native Install and Play. Hold the launch lock through prerequisite setup. On success, require a completed dependency manifest on the writable volume, then report the restart checkpoint. Report prerequisite rejection and timeout separately so a fresh session does not confuse an incomplete dependency with a successful setup. Preserve Steam's ordinary per-title path, entitlement and installed-state checks in the fresh process.

Use the app's foreground restart request for a completed dependency and carry one resume request as Xbox activation arguments, scoped to the current Steam account and selected AppID. The XAML app passes those arguments to the packaged account page through a consumed local setting. StartPage probe packages receive the activation directly. A restart request that returns control to the current process leaves a diagnostic and a manual reopen message. On restart, consume the request once, confirm the Steam account and ownership, and submit the same Play through the normal entry point. Suppress an automatic restart on the resumed attempt. [UWP foreground restart](https://learn.microsoft.com/en-us/uwp/api/windows.applicationmodel.core.coreapplication.requestrestartasync)

## Console acceptance

Series X OS `26100.9673` and GabeBox `1.0.232.3` verified the warm path for Slay the Spire (`646570`, Steam build `10180494`). Slay and Common Redistributables (`228980`, build `24098430`) both had complete manifests on writable volume `D`. Stock Play reached the Slay title screen in launch `1795533511047`. An independent review confirmed that changing the default drive would still find the completed `D` manifest before other drives. A cold run needs a library isolated from that path. The stock UI serializes installs, so deterministic competing queue evidence needs a second transfer in the same Steam session.
